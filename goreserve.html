Project Overview

Go Reserve is a web-based event reservation platform designed to make it easier to explore events and manage bookings. It includes an interactive seat-selection experience and an administrative interface.

Key Features

Event Discovery

Browse listed events and explore their details.

Interactive Seat Selection

Choose seats using a visual seating interface.

Booking Management

Review and manage reservation details.

Admin Dashboard

Manage events and reservations from an administrative panel.
